# Customer Service Guidance Skill

OTA酒店客服辅导助手，提供用户安抚、投诉处理、沟通话术等通用指导。

## 功能特点

- 📋 **场景化辅导** - 针对不同客服场景提供专业话术和沟通策略
- 🎯 **结构化输出** - 场景分析、沟通思路、话术参考、注意事项四步法
- ⚠️ **风险识别** - 自动识别高风险场景（媒体、法律、极端行为等）并提示升级
- 🚫 **红线控制** - 不提供具体赔付金额、业务规则、升级建议等敏感内容

## 适用场景

### 常规场景
1. 用户情绪激动/不满
2. 用户不认可处理方案
3. 需要解释说明
4. 复杂投诉处理

### 特殊场景（自动识别并提示升级）
- 媒体相关（记者、曝光、报道等）
- 直播相关（直播间、拍摄、录制等）
- 法律相关（律师、起诉、法院等）
- 极端行为（自残、自杀、伤害等）
- 特殊身份威胁

## 安装方法

将 `customer-service-guidance.md` 文件复制到你的 Claude Code 项目的 `.claude/skills/` 目录下。

```bash
cp customer-service-guidance.md ~/.claude/skills/
```

## 使用方法

### 命令行调用（如果系统支持）
```
/customer-service-guidance 用户说XXX，我该怎么回应？
```

### 直接提问
向 AI 助手描述客服场景，例如：
- "用户说酒店设施有问题要求全额退款，态度很强硬，我该怎么回应？"
- "遇到用户投诉航班取消要求取消订单的场景，怎么安抚用户？"
- "用户质疑发票开具涉嫌偷税漏税，有什么话术建议吗？"

## 输出格式

AI 会按照以下结构提供辅导建议：

### 1. 场景分析
- 用户当前情绪状态
- 核心诉求识别
- 可能的顾虑点

### 2. 沟通思路
- 建议的沟通策略
- 需要传达的关键信息
- 应避免的表达方式

### 3. 话术参考
- **开场话术** - 建立连接和信任
- **核心话术** - 说明情况或提供方案
- **收尾话术** - 确认理解和后续

### 4. 注意事项
- 可能的风险点
- 需要升级的情况
- 后续跟进建议

## 核心原则

1. **共情为先** - 理解用户情绪，表达同理心
2. **耐心倾听** - 让用户充分表达诉求
3. **清晰解释** - 用用户能理解的语言说明情况
4. **方案导向** - 引导用户关注解决方案
5. **避免承诺** - 不承诺具体赔付标准或业务规则

## 限制与红线

- ⚠️ 不提供具体赔付金额
- ⚠️ 不解释具体业务规则
- ⚠️ 不做承诺性表述
- ⚠️ 不引导用户投诉
- ⚠️ 不给具体升级建议
- ✅ 专注于沟通技巧和话术指导

## 示例

**客服提问**：
> 用户说酒店设施有问题要求全额退款，态度很强硬，我该怎么回应？

**AI 回复**：

#### 场景分析
- 情绪状态：不满、期望明确（全额退款）
- 核心诉求：希望损失得到补偿
- 可能顾虑：担心问题不被重视，感觉权益受损

#### 沟通思路
1. 先安抚情绪，表达理解和重视
2. 了解具体问题细节，让用户感受到被倾听
3. 说明会认真处理，引导用户关注解决过程而非单一方案
4. 避免直接拒绝"全额退款"，但也不承诺具体方案

#### 话术参考

**开场话术**：
"非常理解您的心情，出来旅游遇到这样的情况确实很影响体验。您先别着急，我会认真帮您处理这个问题。能详细说说具体是哪些设施有问题吗？"

**核心话术**：
"感谢您的详细说明，我完全理解您的感受。这个情况我会完整记录并提交给相关部门优先处理。我们的原则是尽量让您的损失降到最低，具体的处理方案需要核实情况后给您答复，但请您放心，我们一定会给您一个合理的解决办法。"

**收尾话术**：
"我现在马上提交您的诉求，最晚XX时间内会有处理结果反馈给您。在等待期间如果您有任何疑问，随时联系我。我的工号是XXX，您这边还有其他需要补充的信息吗？"

#### 注意事项
- 不要被"全额退款"带节奏，避免说"不能全额退"
- 如用户持续激动升级，及时转接主管
- 记录关键信息和证据，便于后续处理
- 设定明确的反馈时间，给用户心理预期
